# Portage feedback

Bug reports and feature requests for [Portage](https://portage.rikard.dev), the media server player for iPhone, iPad and Mac.

- [Report a problem](../../issues/new?template=bug.yml)
- [Suggest a feature](../../issues/new?template=feature.yml)

Issues here are public. Leave out server addresses, account names and tokens. To send something privately, or to attach a log, email hi@rikard.dev or use Settings → Report a problem → By email in the app.
